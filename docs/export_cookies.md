# export_cookies.py — 从浏览器导出 YouTube cookies

从 Chrome / Chromium / Brave / Edge / Firefox 导出 YouTube 的 cookies 为 **Netscape 格式**的 `cookies.txt`，给 yt-dlp 使用。

> 适用场景：yt-dlp 的 `--cookies-from-browser` 在 Linux 上常因 GNOME Keyring 损坏而失败。本工具用 `browser_cookie3` 直接读浏览器 SQLite，更稳。

---

## 一、命令行参数

```
usage: export_cookies.py [-h] [--output OUTPUT] [--domain DOMAIN] [--browser BROWSER]

可选:
  --output, -o OUTPUT    输出 cookies.txt 路径（默认: cookies.txt）
  --domain, -d DOMAIN    cookie 域名过滤（默认: youtube.com）
  --browser, -b BROWSER  浏览器（默认: chrome）
                         可选: chrome / chromium / brave / edge / firefox
  -h, --help             查看帮助
```

---

## 二、典型用法

### 1. 默认（Chrome → cookies.txt）

```bash
python src/export_cookies.py
```

会在当前目录生成 `cookies.txt`。建议放到项目根目录，和 `config.py` 的默认配置对齐：

```bash
python src/export_cookies.py -o cookies.txt
```

### 2. 从 Firefox 导出

```bash
python src/export_cookies.py --browser firefox
```

### 3. 自定义域名（比如要拿音乐子域的 cookie）

```bash
python src/export_cookies.py --domain music.youtube.com
```

### 4. 输出到指定路径

```bash
python src/export_cookies.py -o /path/to/my_cookies.txt
```

## 三、前置准备

### 安装 browser_cookie3

```bash
pip install browser-cookie3
```

> ⚠️ 这个依赖**不在** `requirements.txt` 里（因为只有 cookies 模式才需要）。需要时单独装。

### 关闭浏览器（推荐）

读 cookie 时浏览器最好关闭，避免 SQLite 锁冲突（特别是 Linux 下 Chrome 用 `LOCK` 文件锁）。

---

## 四、生成的文件格式

Netscape 格式（yt-dlp / curl / wget 都认）：

```
# Netscape HTTP Cookie File
# Generated by export_cookies.py

.youtube.com    TRUE    /    TRUE    1234567890    VISITOR_INFO1_LIVE    xxxx
.youtube.com    TRUE    /    TRUE    1234567890    GPS                   yyyy
...
```

每行 8 个 tab 分隔字段：`domain  domain_flag  path  secure  expiry  name  value`

---

## 五、配合 config.py 使用

生成 `cookies.txt` 后，确认 `config.py` 配置：

```python
# config.py
COOKIES_FILE = str(PROJECT_ROOT / "cookies.txt")   # 方式一（推荐）：用文件
COOKIES_FROM_BROWSER = ""                           # 方式二：禁用 browser 提取
```

这样 [main.md](main.md) 和 [download_from_urls.md](download_from_urls.md) 都会自动用这个 cookies 文件。

## 六、为什么要 cookies？

| 场景 | 没 cookies | 有 cookies |
|------|-----------|-----------|
| 下载普通 YT 视频 | 通常可以 | 更稳定，绕过限流 |
| 下载 YT Music 付费版音频 | 不行 | **可以拿到 256 kbps AAC**（需 Premium 账号）|
| 下载年龄限制视频 | 不行 | 可以 |
| 避免被 YouTube 反爬限流（429） | 容易触发 | 更稳 |

## 七、常见问题

### Q: 报错 `browser_cookie3 not installed`

```bash
pip install browser-cookie3
```

### Q: `No cookies found for domain 'youtube.com' in chrome`

可能原因：
1. **浏览器没登录 YouTube** —— 先在浏览器登录
2. **浏览器开着，SQLite 被锁** —— 关掉浏览器重试
3. **域名不匹配** —— Chrome 可能存的是 `.youtube.com`，试试 `--domain .youtube.com`

### Q: 导出后 yt-dlp 还是报 cookies 错误

检查文件格式。Netscape 格式要求第一行是 `# Netscape HTTP Cookie File` 注释，每行 7 字段 tab 分隔。可以用 `head cookies.txt` 看一眼。

### Q: cookie 过期了怎么办

YouTube cookies 一般几个月有效。过期了重跑本脚本刷新即可。

### Q: 安全风险

`cookies.txt` 含登录凭据，**不要提交到 git**。确认 `.gitignore` 里有：

```
cookies.txt
```

本项目的 `.gitignore` 已经包含这条。
